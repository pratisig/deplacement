Table view: the busiest places for the chosen date

Dot size shows everything that moved into, out of or within one place — in records. Line thickness shows the value carried on that route. Hover a dot to see only its routes.

The Layout slider moves between true geography and a network layout: in the network, places that exchange many flows sit close together, so distance has no geographic meaning. Background maps fade out as the network takes over.

Background maps are public tile servers that need no API key and no sign-up: Esri dark gray, Esri light gray, Esri satellite, OpenTopoMap, Wikimedia Maps, OpenStreetMap France and OpenStreetMap. If a server refuses the tiles, the map switches to the next one by itself. Choose None to draw only your own data and boundaries.

Source: IOM DTM Rapid Displacement Tracking, district level. Households are counted from assessments and added up from 4 January to the date chosen, so a family assessed twice counts twice.

Any table works. Press Load data… and drop a CSV, TSV or JSON file with one row per flow — an origin, a destination and a value, plus either coordinates or names that match a boundary file you also load. Nothing is uploaded: the file is read in the browser and stays there. Export writes the current day out as JSON, CSV, GeoJSON, GeoParquet or zipped shapefiles, and the whole period as an animated GIF or a WebM video.
